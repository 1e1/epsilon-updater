Rendus calculatrice — calc.js

Trois modes, une seule fonction : buildCalc({variant, mode}). Finition réaliste et écrans sans texte par défaut (flags internes cachés DEFAULT_FINISH / DEFAULT_TEXTLESS). variant : "graphing" ou "scientific".

Icône famille — mode:"icon"

calc.js › buildIcon()

Rôle : glyphe compact de famille. Quand : cellule « icône » de la table du roster (§5) et partout où il faut distinguer graphique (clair) / scientifique (graphite) d'un coup d'œil. Silhouette d'appareil, lisible dès 24 px, sans texte.

Vignette écran — mode:"thumb"

calc.js › buildThumb()

Rôle : aperçu de l'écran d'accueil dans son cadre. Quand : carte d'aperçu, en-tête de famille, illustration moyenne (~96–160 px) sans encombrer avec le clavier.

Appareil complet — mode:"device" (défaut)

app.js:189 · .calc-slot

Rôle : rendu complet corps + écran + clavier. Quand : vue mono-appareil dans le rail (largeur cible ~112 px). Le clavier garde ses légendes physiques (non localisées).
